# Roku-style Android TV launcher (era themes)

Build with GitHub Actions (push to `main`, then download `app-debug` from the run's Artifacts) or open in Android Studio.

Five menu styles, switchable in Launcher settings: Roku 2008, Roku 2013, Roku 4 (flat), Roku 2024, Roku 2026.
Default is Roku 2024. Open Launcher settings from the sidebar's "Settings" item, the "Launcher settings" tile in
"Jump To", the gear tile in the 2008 style, or the Menu key. Options: menu style, tile size, wallpaper.

All eras default to the purple gradient except 2008 (light body). Era profiles live in `Era.kt`.
